# Jatin Thakur — Portfolio

A single-page developer portfolio built with plain HTML, CSS, and vanilla JavaScript — no framework or build step required. Features a dark, space-themed background with an animated starfield and falling meteors, terminal/code-editor styled project cards, and smooth section navigation.

**Live site:** _add your deployed URL here_

---

## ✨ Features

- **Animated background** — twinkling starfield + falling meteors drifting toward a glowing "planet horizon" at the base of the page
- **Sticky pill navigation** with scroll-based active-link highlighting
- **Terminal-style project cards** — each styled like a code editor window (traffic-light dots, filename, monospace `open-project` command link) with a unique accent color and icon per project
- **Subtle 3D tilt effect** on project cards that follows the cursor (automatically disabled for users with reduced-motion preferences)
- **Fully responsive** layout for desktop and mobile
- **Zero dependencies** — just HTML, CSS, and JS in a single file; fonts loaded from Google Fonts

## 🚀 Running Locally

No build tools or dependencies needed.

```bash
# Clone or download the repo, then simply open the file:
open index.html          # macOS
start index.html         # Windows
xdg-open index.html      # Linux
```

Or serve it locally for a nicer dev experience:

```bash
npx serve .
# or
python3 -m http.server 8000
```

## ☁️ Deployment

This is a static site, so it deploys anywhere in seconds:

**Vercel**
```bash
npm i -g vercel
vercel
```

**Netlify** — drag and drop `index.html` onto [app.netlify.com/drop](https://app.netlify.com/drop)

**GitHub Pages**
1. Push this repo to GitHub
2. Go to *Settings → Pages*
3. Set source to your default branch and root directory
